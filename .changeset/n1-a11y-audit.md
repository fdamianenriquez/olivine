Accessibility fixes found by running axe on every story in a real browser: Pagination shows page numbers without zero padding, so the visible number is part of each page's name ("Page 1"), and the decorative index numbers of Tabs, Nav and Accordion use `ink-2` (4.5:1 or more) instead of `ink-3`; the active tab's index is `ink` (its olivo bar still marks the tab), so it reads on `paper-2` too.
