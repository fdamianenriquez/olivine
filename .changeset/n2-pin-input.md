Add PinInput: a row of joined cells for a fixed-length one-time code or PIN, drawn over one real text input so autofill, paste, undo and screen readers work as in a plain field. Supports `length`, `charset` (numeric or alphanumeric), `sanitize`, `mask`, `group`, three sizes, `onChange(value)` and `onComplete(value)`, and takes its label, hint and error from Field.
