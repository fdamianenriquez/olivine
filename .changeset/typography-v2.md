Typography v2: titles in Big Shoulders Display, interface and reading text in Familjen Grotesk, code and data in Xanh Mono, kanji in Yuji Syuku (opt-in `olivine/fonts-jp.css`); amounts stay in Sprat Condensed. Labels, buttons, badges, tabs and meta lines are sentence case with no letter-spacing (nothing is uppercased outside stamps), table amount columns use the figure face, and glyphs use the label face. New type style `label-s`; the `--font-serif` family is replaced by `--font-heading` and `--font-label`. Redaction, Ronzino, Martian Mono and Zen Old Mincho are no longer shipped.
