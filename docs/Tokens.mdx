# Tokens

Every value in Olivine comes from a token. They are CSS custom properties in
`olivine/tokens.css` (also part of `olivine/styles.css`) and typed values in `olivine/tokens`:

```ts
import { tokens, type ColorToken } from "olivine/tokens";

tokens.color.olivo.washi; // "#6a6a45"
tokens.space["space-6"]; // "24px"
```

| Entry point              | Contains                                                |
| ------------------------ | ------------------------------------------------------- |
| `olivine/styles.css`     | Tokens, fonts, base styles, components and utilities    |
| `olivine/tokens.css`     | Custom properties only, both themes                     |
| `olivine/fonts.css`      | `@font-face` rules only                                 |
| `olivine/fonts-jp.css`   | Opt-in Yuji Syuku for kanji                             |
| `olivine/components.css` | Base styles, components and utilities — no tokens/fonts |
| `olivine/tokens`         | Typed token values for JavaScript                       |

Colour tokens are on the [Colour](?path=/docs/foundations-colour--docs) page and type styles on
[Type](?path=/docs/foundations-type--docs).
