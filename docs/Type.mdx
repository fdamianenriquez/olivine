# Type

Two rules carry the system: **titles in Big Shoulders, amounts in Sprat.** Everything else is
interface in Familjen Grotesk.

| Style                                    | Family                                      | Use                                                                                                              |
| ---------------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `display-xl` / `display-l` / `display-m` | Big Shoulders Display 300 (thin, condensed) | Hero names, page and section titles. One `display-xl` per page; two lines at most.                               |
| `h1`                                     | Big Shoulders Display 400                   | Headings inside content. The condensed face is never set below 40px.                                             |
| `h2` `h3`                                | Familjen Grotesk 600                        | Card / modal / toast / alert titles, list and accordion rows.                                                    |
| `figure-xl` … `figure-s`                 | Sprat Condensed Black                       | Every amount and quantity: prices, totals, stats, counters, table amount columns. Never below 16px, never words. |
| `body-l` `body` `ui` `body-s`            | Familjen Grotesk 400                        | Reading and UI text. Lines ≤ 65ch.                                                                               |
| `label-s` `label` `label-l`              | Familjen Grotesk 500, sentence case         | The interface voice: labels, buttons, badges, tabs, meta. No uppercase, no letter-spacing.                       |
| `mono`                                   | Xanh Mono 400                               | Code, data values, timestamps, IDs.                                                                              |
| `kanji` `kanji-s`                        | Yuji Syuku 400 (brush)                      | Kanji ornaments and vertical captions. Never the only label.                                                     |
| `stamp`                                  | Big Shoulders Display 800, uppercase        | Only inside `.ol-stamp`, the one place text is uppercased.                                                       |

- Don't set the display and figure faces on the same line; give each its own line or cell.
- Each style is available as custom properties: `--text-<style>-family`, `-size`, `-leading`,
  `-weight` and `-tracking`.

## Fonts

All five families are self-hosted and ship in the package's `fonts/` folder (SIL Open Font
License 1.1). `olivine/styles.css` includes the `@font-face` rules for every family except Yuji
Syuku; import `olivine/fonts.css` on its own if you load tokens and components separately.

Yuji Syuku is opt-in, for pages that show kanji:

```ts
import "olivine/styles.css";
import "olivine/fonts-jp.css";
```

It ships its full character set split into `unicode-range` slices, so browsers only download
the slices a page uses, usually a few of 20–60 kB. Without it, kanji fall back to the system's
mincho (Hiragino Mincho, Yu Mincho).
