# Type

Two rules carry the system: **words in Redaction, numbers in Sprat.** Everything else is
interface.

| Style                                    | Family                           | Use                                                                                |
| ---------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------- |
| `display-xl` / `display-l` / `display-m` | Redaction, tight tracking        | Hero names, page and section titles. One `display-xl` per page; two lines at most. |
| `h1` `h2` `h3`                           | Redaction                        | Headings, card / modal / toast / alert titles, list and accordion rows.            |
| `figure-xl` / `figure-l` / `figure-m`    | Sprat Condensed Black            | Numbers only: stats, prices, percentages, counters. Never below 16px, never words. |
| `body-l` `body` `body-s`                 | Ronzino                          | Reading and UI text. Lines ≤ 65ch.                                                 |
| `label`                                  | Martian Mono, UPPERCASE, +0.06em | The system voice: labels, buttons, badges, tabs, meta, `[ BRACKETED ]` actions.    |
| `mono`                                   | Martian Mono                     | Code, data, numeric table columns.                                                 |
| `kanji`                                  | Zen Old Mincho 500               | Kanji ornaments and vertical captions. Never the only label.                       |

- Don't set the display and figure faces on the same line; give each its own line or cell.
- Each style is available as custom properties: `--text-<style>-family`, `-size`, `-leading`,
  `-weight` and `-tracking`.

## Fonts

All six families are self-hosted and ship in the package's `fonts/` folder (SIL Open Font
License 1.1). `olivine/styles.css` includes the `@font-face` rules for every family except Zen
Old Mincho; import `olivine/fonts.css` on its own if you load tokens and components separately.

Zen Old Mincho is opt-in, for pages that show kanji:

```ts
import "olivine/styles.css";
import "olivine/fonts-jp.css";
```

It ships its full character set split into `unicode-range` slices, so browsers only download
the slices a page uses, usually a few of 20–60 kB. Without it, kanji fall back to the system's
mincho (Hiragino Mincho, Yu Mincho).
